1. Общие положения

Настоящая Политика определяет порядок обработки и защиты сведений о пользователях сервиса Tunnelo (далее — Сервис), доступного на сайте tunello.online и в приложениях Сервиса для Android, Windows, macOS, iOS и iPadOS.

Используя Сервис, пользователь подтверждает согласие с настоящей Политикой. Если вы не согласны с её условиями, пожалуйста, прекратите использование Сервиса.

Сервис не требует предоставления паспортных данных, сканов документов, фотографий, адреса проживания и иных сведений, позволяющих установить личность. Регистрация возможна по одному лишь адресу электронной почты.

2. Какие данные мы собираем

Адрес электронной почты. Указывается пользователем при оформлении подписки. Используется для входа в личный кабинет, восстановления доступа и направления сведений об оплате.

Идентификатор устройства. Приложение формирует техническую строку, по которой подписка закрепляется за устройством. Она не содержит номера телефона, серийного номера и иных сведений, позволяющих определить владельца.

Ключ подписки. Случайная строка, выдаваемая при активации. Служит единственным идентификатором учётной записи.

Объём переданных данных. Количество байт, переданных и принятых через Сервис, — для контроля лимитов тарифа.

Сетевые адреса подключений. Фиксируются на время сессии для соблюдения ограничения по числу одновременно используемых устройств.

Сведения о платежах. Номер операции, сумма, валюта, статус, дата и выбранный тариф.

Обращения в поддержку. Текст обращения и контакт, по которому пользователь просил ответить.

3. Чего мы не собираем

Сервис не ведёт журналов посещаемых сайтов, не сохраняет содержимое трафика, поисковые запросы, переписку, файлы и любые иные сведения о том, чем пользователь занят в сети.

Реквизиты банковских карт Сервису не передаются и не сохраняются. Оплата проводится на стороне платёжного сервиса; Сервис получает лишь сведения, перечисленные в пункте 2.

Сервис не собирает биометрические данные, сведения о состоянии здоровья, политических взглядах, вероисповедании и иные специальные категории персональных данных.

4. Зачем нам эти данные

Работа Сервиса. Выдача и продление доступа, соблюдение лимитов тарифа, распределение нагрузки между серверами.

Связь с пользователем. Направление кода для входа, сведений об оплате и ответов на обращения. Рекламные рассылки без отдельного согласия не производятся.

Учёт и статистика. Обобщённые показатели нагрузки и качества соединения. Такие сведения не позволяют определить конкретное лицо.

5. Передача третьим лицам

Сведения о пользователях не продаются, не передаются в рекламных целях и не раскрываются третьим лицам, за исключением случаев:

— передачи платёжному сервису данных, необходимых для проведения оплаты и формирования кассового чека;

— исполнения обязательств перед пользователем, когда это невозможно без привлечения подрядчика;

— случаев, прямо предусмотренных законодательством Российской Федерации, по надлежаще оформленному требованию уполномоченного органа;

— наличия отдельного согласия пользователя.

6. Хранение и защита

Сведения хранятся на серверах, доступ к которым ограничен и защищён ключами. Передача данных между приложением и Сервисом производится по защищённому соединению.

Сведения об учётной записи хранятся, пока действует подписка, и в течение двенадцати месяцев после её окончания — чтобы пользователь мог вернуться и восстановить доступ. Сведения о платежах хранятся в течение сроков, установленных законодательством для бухгалтерских документов.

Коды для входа действуют пятнадцать минут и удаляются после использования.

Мы принимаем разумные меры защиты, однако ни один способ передачи данных через сеть не обеспечивает абсолютной безопасности, и Сервис не может гарантировать её при обстоятельствах, находящихся вне его контроля.

7. Права пользователя

Пользователь вправе запросить сведения о том, какие данные о нём обработаны, потребовать их уточнения, приостановления обработки или удаления, а также отозвать согласие на обработку.

Запрос направляется на адрес {{ email }}. Ответ предоставляется в срок, установленный законодательством. Удаление сведений об учётной записи влечёт прекращение доступа к Сервису.

8. Файлы cookie

Сайт использует одну техническую запись в браузере — для того, чтобы пользователь оставался в личном кабинете между посещениями. Рекламные и аналитические записи сторонних сервисов не устанавливаются.

9. Дети

Сервис не предназначен для лиц младше 18 лет и не собирает их данные осознанно. При обнаружении таких сведений они удаляются.

10. Изменения Политики

Сервис вправе изменять настоящую Политику. Новая редакция вступает в силу с момента размещения на этой странице; дата редакции указана в начале документа. Продолжение использования Сервиса означает согласие с действующей редакцией.
